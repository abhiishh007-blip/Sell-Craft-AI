SETUP

Connect your local AI

SellCraft uses Ollama to run an open-weight language model on your computer. Your product details don't need to go to a third-party AI API.

  1. Install Ollama from ollama.com/download.
  2. Open a terminal and run ollama pull qwen2.5:3b.
  3. Start Ollama and serve this project from http://localhost (not by double-clicking the HTML file). If your browser blocks requests, set OLLAMA_ORIGINS to your local development origin in Ollama's environment settings.
Default endpointhttp://localhost:11434/api/generate

A demo mode is available if Ollama isn't installed yet. Demo output is template-based, not generated by an AI model.
